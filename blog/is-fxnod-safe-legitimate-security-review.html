1. The Non-Custodial Architecture: Why Your Funds Cannot Be Stolen

To understand why your money is safe, you must examine how Deriv API Tokens function.

When you link FXnod to Deriv, you generate an API token inside Deriv’s official portal. Deriv enforces strict permission boundaries on these tokens:

API Token Permission Does FXnod Require It? What It Allows
Read ✅ YES Allows FXnod to fetch your live account balance, open positions, and tick history.
Trade ✅ YES Allows FXnod to place bot contracts on your command according to your rules.
Payments / Cashier ❌ STRICTLY NO Allows depositing or withdrawing money to banks or crypto wallets.
Admin ❌ STRICTLY NO Allows changing passwords, emails, or 2FA credentials on Deriv.

Because FXnod operates exclusively with Read and Trade scopes, the Deriv server will flatly reject any withdrawal or transfer request sent through that token.

Withdrawals can only be executed by you, directly through Deriv’s official website, protected by Deriv's independent Two-Factor Authentication (2FA) and email confirmation codes.

Can FXnod steal or withdraw my money from Deriv?

No. It is mathematically and technically impossible. Deriv's API token architecture strictly prohibits withdrawals through third-party tokens. Only you can authorize withdrawals inside Deriv's official cashier portal.

Can FXnod change my Deriv password or account email?

No. FXnod never receives "Admin" permissions. It has zero capability to alter your personal profile settings, passwords, or security preferences on Deriv.

What happens if FXnod servers go down while a bot is running?

Each contract dispatched to Deriv has an embedded duration (e.g., 1 tick or 5 ticks). Once accepted by Deriv, the contract settles independently on Deriv's servers whether FXnod is online or offline. Furthermore, FXnod’s background sentinel guards prevent initiating new trades during server reconnects.

Is my API token stored securely?

Yes. Your API token is transmitted over TLS-encrypted channels and stored using industry-standard hashing and encryption protocols. You can also revoke or regenerate this token on Deriv at any second.

Is automated bot trading allowed by Deriv?

Yes. Deriv is one of the world's most developer-friendly brokers and actively encourages algorithmic automation through their public API ecosystem and developer portal.
